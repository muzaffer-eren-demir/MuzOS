# MuzOS
Düzenlenerek farklı mikrodenetleyicilerde ve birçok projede kullanılabilecek kernel, işletim sistemi iskeleti.
## Mevcut Durum:
Kernel'in scheduler yapısı temel düzeyde oluşturuldu. Sıraya eklenen görevler gerçekleştirlir. Aksi durumlarda -blackhole- fonksiyonuna gidilir.
## Yapılacaklar:
Global değikenlerden kurtulmak.
Yapıya kesmeleri dahil etmek.
Henüz öngörülmemiş problemleri aşmak.
